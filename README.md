# Meu-primeiro-projeto-em-python
Projeto simples em python com script executável 
## Descrição
Esse projeto é uma calculadora simples feita em Python.
Ela realiza operações básicas como soma, subtração, multiplicação e divisão.
O projeto também possui um arquivo '.sh' , que permite executar o código python de
forma simples pelo terminal.

-Bash
